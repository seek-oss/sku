# Tasks

## 1. Production keep-alive

- [x] 1.1 After a successful production `listen`, and before `onListen`, set `keepAliveTimeout` to 35000. Do not change `headersTimeout`. `sku start` does not set it. Ship with tasks 2.2 and 2.3, because without them a finished in-flight socket outlives the 25 second deadline. Verify: a production server test sees 35000 and headers timeout 60000 when `onListen` leaves them alone, and `sku start` stays at 5000.
- [x] 1.2 Do not change or check `headersTimeout` after `onListen`. Verify: a `keepAliveTimeout` of 65000 set in `onListen` is kept, and headers timeout stays 60000.

## 2. SIGTERM drain

- [x] 2.1 Add optional `onShutdown` to `defineServerEntry` and `SkuServerEntry`. Verify: a server entry without `onShutdown` type-checks and listens.
- [x] 2.2 After `onListen` returns, register one production `SIGTERM` listener, and none from `sku start`. In production, fail startup when a listener already exists. The error gives the listener count and any function names, says a dependency can register one, points to `onShutdown`, says to turn off a dependency's listener with its own option or function first, and says to call `process.removeAllListeners('SIGTERM')` in `onListen` only when the dependency has neither. Keep the listener until the process exits. Verify: one listener in production, none from sku in `sku start`, an existing listener fails startup with that message, and a repeated `SIGTERM` after the server closes during `onShutdown` is ignored.
- [x] 2.3 On `SIGTERM`, stop accepting and close sockets with no in-flight response without waiting `keepAliveTimeout`, on Node 24 and Node 26. That includes an idle keep-alive, and a connected socket that has sent no bytes, which Node 24's `close()` leaves open and its headers timer only closes after 60 seconds or more. Verify: both socket kinds close promptly on each Node major.
- [x] 2.4 For an in-flight response that has not sent headers, send `Connection: close`. When any in-flight response finishes, close its socket without waiting `keepAliveTimeout`. Verify: the header is present only when headers were not yet sent, and the socket closes when the response ends.
- [x] 2.5 On `SIGTERM`, start an `unref`ed 25 second timer that exits 1. Verify with fake timers: a response that never ends exits 1 at 25 seconds without calling `onShutdown`, and a drain that finishes early exits 0 without waiting.
- [x] 2.6 Await `onShutdown` with no arguments after responses finish, then exit 0. Report a throw or rejection and continue. Verify: order is response, then `onShutdown`, then exit 0; a rejected `onShutdown` still exits 0.
