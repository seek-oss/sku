Drop support for React 18.x

**BREAKING CHANGE**

React 18 is no longer supported. Consumers must upgrade to React 19. Follow the [React 19 upgrade guide] and make sure any dependencies that rely on React are compatible with React 19.

The "React 18 or below detected" warning shown by `sku configure` has been removed.

[React 19 upgrade guide]: https://react.dev/blog/2024/04/25/react-19-upgrade-guide
